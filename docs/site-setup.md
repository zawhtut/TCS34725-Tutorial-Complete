# GitHub Pages Setup (Maintainer Only)

This page is kept for the repository maintainer, not the course tutorial sidebar.

In GitHub repository settings, under **Pages**, select **Deploy from a branch**, then branch `main` and folder `/docs`. The existing `docs/_config.yml` controls the Just the Docs theme. Do not modify the main RGB sensor assignment repository to publish this tutorial.
